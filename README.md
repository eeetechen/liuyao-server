# 六爻排盘服务（Go）

前后端分离的京房纳甲六爻排盘系统。Go 服务端提供确定性 JSON API，
原生 HTML/CSS/JS 前端同时适配手机与电脑。

结果中明确给出 **旺相休囚死**、**暗动**（含日破 / 月破）与 **六冲** 判定。

---

## 快速开始

```bash
# 1) 获取依赖
go mod download

# 2) 启动服务（默认 :8080）
go run ./cmd/server
# 或指定端口
go run ./cmd/server -addr :9000

# 3) 打开浏览器
open http://localhost:8080
```

前端已通过 `go:embed` 编译进二进制，因此也可以脱离源码目录独立部署：

```bash
go build -o liuyao-server ./cmd/server
./liuyao-server -addr :8080
```

---

## 架构

前后端完全分离，前端只通过 HTTP JSON 与后端通信（已开启 CORS）。

```
.
├── cmd/server/              服务入口（含优雅关闭）
├── internal/
│   ├── api/                 HTTP 路由与请求/响应契约
│   ├── calendar/            农历↔干支历（四柱、节气月、旬空、换日口径）
│   ├── cast/                摇卦（三枚铜钱，crypto/rand）
│   └── divination/          排盘引擎（纯函数、零 IO、可独立测试）
├── web/                     响应式前端（原生 JS，无框架无构建）
└── assets.go                go:embed 前端资源
```

分层原则：`divination` 不依赖时间库也不做 IO，只接收已算好的干支，
因此可用固定时间做确定性单元测试。

## API

### `GET /api/health`
健康检查。

### `GET /api/meta`
返回爻值字典与摇卦方式（供其他客户端使用）。

### `GET /api/cast`
摇卦（三枚铜钱掷六次）。可选 `?at=2024-01-01 12:00` 指定起卦时间。

```json
{
  "results": [{"value":9,"backs":3,"yinYang":"yang","moving":true}, ...],
  "values": [9,7,8,6,7,8],
  "time": { "year":"癸卯", "day":"甲子", "xunKong":"戌亥", ... }
}
```

### `GET /api/reference`
返回**五行生克参考表**（静态字典），供使用者查询印证：

| 字段 | 内容 |
|---|---|
| `wuXing` | 五行属性：五色、方位、季节、生我/我生/克我/我克 |
| `shengKe` | 五行生克 10 条：木生火、水克火…各附白话解释 |
| `tianGan` | 十天干：五行、阴阳 |
| `diZhi` | 十二地支：五行、阴阳、生肖 |
| `liuChong` | 六冲 6 组：子午、丑未、寅申、卯酉、辰戌、巳亥 |
| `liuHe` | 六合 6 组：子丑合土、寅亥合木… |
| `sanHe` | 三合 4 局：申子辰水、亥卯未木、寅午戌火、巳酉丑金 |
| `banHe` | 半合 8 组 |
| `xing` | 三刑 7 组（寅巳申、丑戌未、子卯 + 辰午酉亥自刑） |
| `hai` | 六害 6 组（子未、丑午、寅巳、卯辰、申亥、酉戌） |
| `liuShen` | 六神（六兽）意象 6 条：五行、对应色、起初爻日干、吉凶倾向、意象、释义 |
| `notes` | 口径说明 |

> 例：查「水克火」→ `shengKe`；查「卯属什么」→ `diZhi`（卯=阴木，生肖兔）；
> 查「六冲有哪些」→ `liuChong`。

### `POST /api/chart`
排盘主接口。

| 字段 | 类型 | 说明 |
|---|---|---|
| `yaoValues` | int[6] | **必填**，六爻值自下而上，取值为 6/7/8/9 |
| `question` | string | 所问之事，**可选**。前端已不提供此输入 |
| `method` | string | `coin` 或 `manual` |
| `at` | string | 起卦时间，`RFC3339` 或 `2006-01-02 15:04`，留空取当前 |
| `timezone` | string | 时区名，默认 `Asia/Shanghai` |
| `dayBoundary` | string | 换日口径 `zi`(默认) / `midnight`，见下文 |
| `yongShen` | string | 用神六亲（父母/兄弟/子孙/妻财/官鬼）。留空时：有 `question` 则依其推断，否则默认妻财 |

爻值含义（传统记法）：

| 值 | 名称 | 阴阳 | 动静 | 三枚铜钱背面数 |
|---|---|---|---|---|
| 6 | 老阴 | 阴 | **动**（阴变阳） | 0 |
| 7 | 少阳 | 阳 | 静 | 1 |
| 8 | 少阴 | 阴 | 静 | 2 |
| 9 | 老阳 | 阳 | **动**（阳变阴） | 3 |

请求示例：

```bash
curl -X POST http://localhost:8080/api/chart \
  -H 'Content-Type: application/json' \
  -d '{"yaoValues":[8,8,8,8,8,8],"yongShen":"官鬼",
       "at":"2024-01-08 10:00","timezone":"Asia/Shanghai"}'
```

## 判定规则

### 旺相休囚死

以**月建**为准（口诀：同我者旺，我生者相，生我者休，克我者囚，我克者死，
此处「我」指月令）：

| 状态 | 关系 | 力量 |
|---|---|---|
| 旺 | 与月令同五行 | 最强 |
| 相 | 月令所生 | 次强 |
| 休 | 生月令（泄气） | 平平 |
| 囚 | 克月令（耗力） | 较弱 |
| 死 | 被月令所克 | 最弱 |

### 暗动 / 日破 / 月破

仅对**静爻**判定（明动之爻已发动，不受冲破约束）：

1. **月破**：爻支被**月建**所冲 → 不论旺衰，整月无力，重於日破。（优先判定）
2. **暗动**：爻支被**日辰**所冲，且该爻**旺相** → 旺相逢冲为暗动。
3. **日破**：爻支被**日辰**所冲，且该爻**休囚死** → 休囚逢冲为日破。

即所谓「旺相逢冲为暗动，休囚逢冲为日破」。

### 六冲

八纯卦（内外卦相同）共 8 个，另加**天雷无妄**、**雷天大壮**，共 **10** 个六冲卦。
变卦为六冲时另有「终恐冲散」提示。**六合卦共 8 个**。

### 其它

- **六亲**：生我者父母、我生者子孙、克我者官鬼、我克者妻财、比和者兄弟（以卦宫五行为我）
- **六神**：甲乙起青龙、丙丁起朱雀、戊起勾陈、己起螣蛇、庚辛起白虎、壬癸起玄武
- **世应**：依《寻世诀》；**卦宫**依《认宫诀》
- **伏神**：六亲不全时，取本宫卦（八纯卦）中所缺六亲之爻
- **旬空**：由日柱所在旬推得；空爻逢日辰冲谓之「冲空」，空而反实

### 五行生克

逐爻给出**月建**与**日辰**对该爻的作用（`relations.shengKe`）：

| 关系 | 含义 | 力量 |
|---|---|---|
| 生 | 日月五行生爻 | 得生，助益 |
| 扶 | 与日月同五行（比和） | 得扶，助益 |
| 泄 | 爻生日月五行 | 泄气，耗损 |
| 耗 | 爻克日月五行 | 耗力，损减 |
| 克 | 日月五行克爻 | 受克，受损 |

**世应关系**（`relations.shiYing`）以「应对我（世）的作用」立论：
应生世为得助、应克世为受制、比和为同心、世生应为付出、世克应为我制彼。

### 三合 / 半合

| 三合局 | 合化 |
|---|---|
| 申子辰 | 水局 |
| 亥卯未 | 木局 |
| 寅午戌 | 火局 |
| 巳酉丑 | 金局 |

参与范围为六爻地支加月建、日辰。**三支俱全**为三合局；**仅两支**且构成
生半合（申子·亥卯·寅午·巳酉）或墓半合（子辰·卯未·午戌·酉丑）者为**半合**。

> 三合局内另两组（申辰、亥未、寅戌、巳丑）传统称「拱合」，不作半合论，
> 故未列入。已成三合局者不再重复列为半合。

### 六合

子丑合土、寅亥合木、卯戌合火、辰酉合金、巳申合水、午未合土。
按参与方分类给出：爻间 / 爻与日辰 / 爻与月建。

- 日辰合爻 → 谓之**合起**，爻得日辰维系
- 月建合爻 → 得月令维系
- 动爻逢合 → 作**合起**论；两静爻相合 → 作**合绊**论

> **关于「午未」的异说**：多数典籍及严谨实现作合化**土**（未为土之本气，
> 且午火生未土），亦有作合化**火**者，另有一派主张午未为日月之合、合而不化。
> 本实现采合化土，集中于 `LiuHeZhi` 一表，如需改口径只改该处。

### 六冲

子午、丑未、寅申、卯酉、辰戌、巳亥相冲。范围与六合同，另区分：

- 日辰冲**旺相**之静爻 → **暗动**
- 日辰冲**休囚**之静爻 → **日破**
- 月建冲爻 → **月破**（不论旺衰，整月无力）
- 爻间相冲：动爻冲静爻则被冲者受伤；两静爻相冲则冲力甚微

> 注：**卦体六冲**（八纯卦 + 天雷无妄 + 雷天大壮，共 10 卦）与上述
> **地支六冲**是两套不同概念，本服务分别以 `benGua.type` 与
> `relations.liuChong` 输出。

### 三刑 · 六害

| 类别 | 内容 |
|---|---|
| 无恩之刑 | 寅、巳、申 |
| 恃势之刑 | 丑、戌、未 |
| 无礼之刑 | 子、卯 |
| 自刑 | 辰、午、酉、亥（同一支出现两次以上） |
| 六害 | 子未、丑午、寅巳、卯辰、申亥、酉戌 |

参与范围为六爻地支加月建、日辰（日月之间不论）。三刑须三支俱全
（子卯为两支），自刑须同支重现。刑主刑伤、纠纷、官讼、人际失和；
害主暗损、猜忌、小事牵绊，其力弱于刑冲。输出于 `relations.xing` / `relations.hai`。

### 六神（六兽）意象

按**日干**起初爻、顺次上排：

| 起法 | 初爻起 |
|---|---|
| 甲乙日 | 青龙 |
| 丙丁日 | 朱雀 |
| 戊日 | 勾陈 |
| 己日 | 螣蛇 |
| 庚辛日 | 白虎 |
| 壬癸日 | 玄武 |

**五行归属**（据《起身例纳甲·六神总论》）：

| 六神 | 五行 | 色 | 吉凶 | 主要意象 |
|---|---|---|---|---|
| 青龙 | 木 | 青 | 吉 | 喜庆、财喜、升迁、贵人、酒色 |
| 朱雀 | 火 | 赤 | 中 | 文书、信息、口舌、是非、争讼 |
| 勾陈 | 土 | 黄 | 凶 | 田土、房产、迟滞、拘束、勾连 |
| 螣蛇 | 土 | 黄 | 凶 | 虚惊、怪异、忧疑、缠绕、梦寐 |
| 白虎 | 金 | 白 | 凶 | 凶伤、疾病、丧事、血光、道路 |
| 玄武 | 水 | 黑 | 凶 | 盗窃、暗昧、欺骗、遗失、阴私 |

> **一处易混之处**：六壬**十二将**体系中「螣蛇火将、勾陈土将」，
> 而六爻纳甲体系中 **螣蛇属土**。两者是不同体系，不可混用。
> 本实现依六爻口径取土，并在参考表说明中标注此差异。

六神只论吉凶之象，**本身不论旺衰**；须结合所临之爻的旺衰、动静、空破综合判断。

### 用神 · 四神

用神即所占之事的**主爻**，按所问之事取对应六亲。前端以**下拉框**直接指定，
下拉框下方常驻显示该用神的取用参考文本：

| 用神 | 所主之事 |
|---|---|
| 妻财 | 求财、买卖、投资、婚姻（男占妻） |
| 官鬼 | 工作、事业、功名、官讼、疾病 |
| 父母 | 学业、考试、文书、房产、长辈、上级 |
| 子孙 | 子女、生育、平安、解忧、宠物 |
| 兄弟 | 同辈、合作、竞争、借贷 |

**取用方式**（`yongShen` 留空时的回退链）：

1. 若提供 `question`，依其中的关键词匹配主题（规则表 `TopicRules`，20 余组
   中文关键词），命中则取对应六亲，并置 `inferred=true`；
2. `question` 为空或未命中 → 取**妻财**（财为养命之源，古法无主题时多以财论）。

无论哪种方式，`topic` 字段都会给出标准主题名（`TopicByYongShen`），
不会出现「通用（未识别主题）」这类无意义标注。

**取用次序**：本卦现则取本卦 → 本卦无则取变爻所出 → 变卦亦无则取伏神 →
遍寻不得则以日月权代（`selection` 字段为 `visible`/`changed`/`fushen`/`missing`）。

**同六亲多现**时按「取动 → 取暗动 → 取持世 → 取临应 → 舍空取实 → 舍破取全」
之序择定主用神，并置 `ambiguous=true` 提示须兼看，`selectNote` 给出取舍理由。

**四神**（`yuanShen`/`jiShen`/`chouShen`）一律**相对卦宫五行**推算，不可相对用神：

```
用神 Y、卦宫五行 G：
  原神 = 生 Y 者（以 G 为我取六亲）
  忌神 = 克 Y 者（以 G 为我取六亲）
  仇神 = 生忌神者（以 G 为我取六亲）

例：乾宫属金，用神取官鬼（火）
  原神：生火者木 → 木在乾宫为妻财
  忌神：克火者水 → 水在乾宫为子孙
  仇神：生水者金 → 金在乾宫为兄弟
  校验：兄弟金克妻财木＝仇神克原神；金生水＝仇神生忌神 ✓
```

> 开发中此处一度把六亲相对**用神**而非**卦宫**推算，导致四神错乱，
> 由 `TestShenOfDerivation` 与 `TestShenOfInvariants`（对全部卦宫×全部
> 用神校验「原神生用神、忌神克用神、仇神生忌神且克原神、四神互异」）发现并修正。

### 换日口径（重要）

子时跨日历来有「早子时 / 晚子时」两说，直接决定**日辰**，进而影响暗动与日破判定。
本服务将其显式化，避免歧义：

| 取值 | 含义 |
|---|---|
| `zi`（默认） | 23:00 换日，晚子时属**次日** |
| `midnight` | 00:00 换日，晚子时仍属**当日** |

两者**仅在 23:00–23:59 起卦时**产生不同结果。

## 前端

- 原生 HTML/CSS/JS，**零依赖、零构建**，直接由 Go 服务托管
- **起卦为逐爻手动指定**阴阳与动静（初爻在下），不提供自动摇卦
- **本卦与变卦左右并列**对照（含各自卦宫、五行、上下卦、世应、六爻纳甲），
  窄屏可**横向滑动**查看；六爻皆静时变卦位显示「无变卦」
- **年份标注**醒目显示（如「丙午年（马年）」），并提示年份以立春为界
- **白话解析**：由确定性规则生成的通俗说明，分时间/卦体/动静/关键爻/生合冲克
  五节，另有行动建议与免责声明
- 结果下方分块展示 **五行生克 / 三合 / 六合 / 六冲**
- **用神体系**区块：四神链（原神→用神→忌神→仇神）、取用说明、主用神详表
  （旺衰/动静/空破/伏神）、并见候选、逐条断语
- 起卦区有**用神下拉框**，可留空自动或手动指定六亲
- **三刑六害**区块，附刑害释义
- **六神意象**卡片（含五行、吉凶、意象、释义）附于参考表
- **五行生克参考表**（页），可查五行属性、生克、天干地支五行、六冲六合三合半合、三刑六害、六神意象
- 响应式：断点 `1024px`（单列）与 `640px`（手机）
- 手机端卦盘与生克表由表格转为**流式卡片布局**，实测 320 / 360 / 390 / 414 px
  宽度下**无横向滚动**；表头隐藏时以 `data-label` 补出列义
- 爻符号用 **CSS 绘制**而非 Unicode 方块字符，避免不同平台字体导致的
  粗细与断口差异
- 深色朱砂配色，五行以传统五色区分

### 服务端仍保留摇卦接口

前端虽不提供自动摇卦，`GET /api/cast` 仍保留（`crypto/rand` 三枚铜钱），
便于命令行或其他客户端调用。core 的 `internal/cast` 包亦有完整测试。
